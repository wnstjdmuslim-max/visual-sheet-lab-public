03 / COLOR SHEET INPUT
컬러 시트는 6–12장의 레퍼런스에서 시작한다
업로드부터 분석 실행까지, 입력은 단순하고 결과는 반복 가능하게 설계되어 있습니다.
01

이미지 업로드

JPG/PNG 6~12장을 드래그&드롭하거나 데모 세트로 불러옵니다.

02

순서와 프레임 조정

이미지 순서를 정리하고 6·9·12컷과 CROP·FIT 방식을 선택합니다.

03

ANALYZE COLOR

분석을 실행하면 팔레트와 MOOD·EXPOSURE 등 지표가 생성됩니다.

TIP — 장면의 공통 분위기를 보여주는 이미지를 고르면 평균 팔레트가 더욱 해석 가능한 시각 언어가 됩니다.
